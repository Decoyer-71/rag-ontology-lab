이 프로젝트의 메모리 폴더는 **저장소 `.claude/memory/` 를 가리키는 정션**이다(2026-09-11, `link_memory.ps1`).
여기 쓰는 모든 메모리는 **공개 GitHub 저장소에 커밋된다.**

적지 않는 것 — 이메일 · 실명 · 전화번호 · 계정명이 든 경로(`C:\Users\<계정>`) · 호스트명 · 토큰·키 · 사적인 맥락.
사람을 가리킬 때는 역할(「학습자」·「사용자」)로 쓴다.

**Why:** 두 PC 사이에 메모리를 옮길 길이 손 복사뿐이라 정션으로 git 에 태웠다. 그 대가로 메모리가 공개된다.
`.githooks/` 개인정보 관문이 커밋 전에 한 번 더 보지만 규칙은 근사다 — 1차 방어선은 **안 적는 것**이다.

**How to apply:** 메모리를 쓰기 전에 「이 문장이 공개 README 에 실려도 되는가」를 묻는다. PC 고유 값(루트·디스크)도
적지 않는다 — 그건 `CLAUDE.md` §2 의 PC 별 열에 있다. 관련: [[git-identity-yoon71]] · [[two-pc-sync-gate]]
