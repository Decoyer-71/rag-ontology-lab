# 부가서비스 안내

## 데이터 관련

### 데이터 세이프
기본 데이터 소진 후에도 추가 요금 없이 3Mbps 속도를 보장합니다. 월 5,500원.
5G프리미엄, 5G스탠다드 요금제에서만 가입할 수 있습니다.

### 데이터 쉐어링
보유한 데이터를 태블릿, 스마트워치 등 다른 기기와 나눠 쓸 수 있습니다. 월 3,300원.

## 통화 관련

### 국제전화 정액
국제전화를 월 정액으로 이용합니다. 월 9,900원에 주요 10개국 100분.
국제전화 이용 신청이 선행되어야 합니다.

### 통화 매니저
스팸 차단, 통화 녹음, 부재중 알림을 제공합니다. 월 2,200원.

## 안심 서비스

### 분실 안심
단말기 분실 시 수리비 또는 교체비를 지원합니다. 월 5,900원.
가입은 단말기 개통일로부터 30일 이내에만 가능합니다.

### 자녀 안심
위치 확인과 유해 사이트 차단을 제공합니다. 월 3,300원.
