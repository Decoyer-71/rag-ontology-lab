# 사내 용어집 (일부)

⚠ 이 문서는 2025년에 일부만 작성되고 갱신이 중단되었습니다.

| 용어 | 뜻 |
|---|---|
| 개통 | 회선을 사용 가능한 상태로 만드는 절차 |
| 정지 | 회선을 일시적으로 사용 불가로 만드는 것. 해지와 다름 |
| 직권 해지 | 회사가 이용자의 신청 없이 계약을 종료하는 것 |
| 자급제 | 통신사를 거치지 않고 구입한 단말기 |

작성되지 않은 항목: 선택약정, 결합 회선, 그 외 현장 용어 다수.
