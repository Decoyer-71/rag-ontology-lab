# 상담 매뉴얼 — 해지 업무

## 1. 해지 접수 경로

해지는 고객센터, 대리점, 온라인 세 경로로 접수합니다.
온라인 해지는 본인 인증 후 즉시 처리되며, 대리점은 신분증 확인이 필요합니다.

## 2. 해지 전 확인 사항

상담사는 해지 접수 전에 다음을 반드시 확인합니다.

1. 약정 잔여 기간과 할인반환금 발생 여부
2. 단말기 할부금 잔액
3. 결합 상품 가입 여부 — 결합 회선 중 하나를 해지하면 나머지 회선의 할인이 조정됩니다
4. 부가서비스 자동 해지 여부

## 3. 일괄해지 처리

동일 명의 3회선 이상을 같은 날 해지하는 경우 일괄해지 절차를 적용합니다.
일괄해지는 팀장 승인이 필요하며, 명의도용 여부 확인 절차가 추가됩니다.
회선별로 할인반환금이 각각 산정되므로 총액을 합산해 고객에게 안내합니다.

## 4. 해지 철회

해지 접수 후 처리 완료 전까지는 철회할 수 있습니다.
번호이동으로 해지된 경우에는 철회가 불가하며, 신규 가입 절차를 따라야 합니다.

## 5. 해지 고객 응대 원칙

해지 의사를 밝힌 고객에게 부가서비스를 권유하지 않습니다.
해지 사유를 확인하되 3회 이상 만류하지 않습니다.
