# 할인반환금 산정 기준

## 1. 적용 대상

선택약정(요금할인 25%) 또는 공시지원금을 받고 가입한 이용자가
약정 기간 만료 전 해지하거나 하위 요금제로 변경하는 경우 적용됩니다.

## 2. 산정 구간

| 경과 기간 | 반환 비율 | 비고 |
|---|---|---|
| 6개월 미만 | 100% | 받은 할인액 전액 |
| 6개월 ~ 12개월 | 60% | |
| 12개월 ~ 18개월 | 35% | |
| 18개월 ~ 24개월 | 15% | |
| 24개월 이상 | 0% | 약정 만료 |

## 3. 반환금 코드 체계

내부 청구 시스템에는 반환금 유형이 코드로 기록됩니다.

| 코드 | 유형 |
|---|---|
| W01 | 선택약정 해지 반환금 |
| W02 | 공시지원금 해지 반환금 |
| W03 | 요금제 하향 변경 반환금 |
| W09 | 일괄해지에 따른 합산 반환금 |

## 4. 면제 사유

군 입대, 해외 이주, 사망의 경우 증빙 제출 시 반환금이 면제됩니다.
서비스 품질 불만에 의한 해지는 품질 측정 결과에 따라 개별 심사합니다.
