# 진도 기록

> ⚠⚠ **성공만 적지 마십시오.** 「막혔던 곳」과 「폐기한 접근」이 이 문서의 본체입니다.
> README 「배운 것」 절이 여기서 나옵니다(`../CLAUDE.md` §13-3).
>
> *"청킹을 글자수 512로 했더니 요금표가 잘려 숫자 답변이 전부 틀렸다. 조 단위로 바꾸니
> Recall@5 가 0.48 → 0.71"* — **이런 한 줄이 이력서 한 장보다 강합니다.**
> 매끈하게 성공만 적힌 저장소는 읽는 사람이 안 믿습니다.

기계가 읽는 상태는 `.claude/state/progress.json` 에 있습니다. 이 파일은 **사람이 읽는 쪽**입니다.

## 기록 형식

각 단계를 닫을 때 `checkpoint` 스킬이 아래 형식으로 추가합니다.

```markdown
## Stage N — <제목>  (YYYY-MM-DD 완료)

- 능력 목표: (한 문장)
- 측정: (기준선 → 결과. ⚠ 분모 포함)
- ⚠ 막혔던 곳: (무엇이 왜 안 됐는지. 없었으면 "없음")
- 폐기한 접근: (시도했다 버린 것과 그 이유. 없으면 "없음")
- 참조 구현 대조: (내 구현과 무엇이 달랐는지)
- 소요: (실제 시간)
```

## 복습 기록 (CLAUDE.md §14)

`review` 스킬이 카드를 돌릴 때마다 여기 한 줄씩 남깁니다. **틀린 것을 반드시 적습니다.**

```markdown
- YYYY-MM-DD 복습: <카드id> 실패 — <무엇을 못 떠올렸는지>. <어디로 되돌아갔는지>
- YYYY-MM-DD 복습: <카드id> 성공 — <처음 짤 때와 무엇이 달라졌는지>
```

⚠⚠ **「무엇을 잊었는가」가 「무엇을 배웠는가」보다 강한 재료입니다.**
매끈하게 성공만 적힌 복습 기록은 읽는 사람이 안 믿습니다(§13-3).

⚠ 기계가 읽는 원본은 `outputs/metrics/review_log.json` 입니다. 여기는 **사람이 읽는 쪽**이고,
숫자가 아니라 **왜 틀렸는지**를 적는 자리입니다.

(아직 없음 — 카드는 Stage 1 을 `checkpoint` 로 닫을 때 처음 만들어집니다)

### ⚠ 이 단계에서 실제로 밟은 지뢰

**성공만 적으면 이 문서의 의미가 없으므로 여기서부터 지킵니다.**

| # | 무엇이 | 왜 | 어떻게 |
|---|---|---|---|
| 1 | Bash heredoc 으로 한글 `CLAUDE.md`(약 20KB)를 쓰려다 `unexpected EOF` 로 깨짐 | 따옴표·백틱이 섞인 긴 한글 문서는 셸을 통과하며 깨진다 | `Write` 도구로 전환. `CLAUDE.md` §6 지뢰 4 에 기록 |
| 2 | 파이썬 스크립트가 `UnicodeEncodeError: cp949` 로 죽음 | Windows 파이썬 stdout 기본 인코딩이 cp949 다. `—`(em dash) 하나에 터졌다 | `PYTHONIOENCODING=utf-8`. §6 지뢰 8 |
| 3 | ⚠⚠ **훅의 한글 차단 사유가 cp949 로 나감** | PowerShell 5.1 의 `[Console]::OutputEncoding` 기본값이 OEM 코드페이지. Claude 가 받는 건 깨진 글자 → **왜 막혔는지 못 읽어 훅이 반쯤 무력화** | 모든 훅에 UTF-8 고정 삽입 + `.ps1` 에 BOM |
| 4 | ⚠⚠ **자가 시험이 「전부 통과」라고 거짓 보고** | `powershell -Command "... \| & '$hook'"` 로 부르면 훅의 `exit 2` 가 **바깥 프로세스에 전달되지 않는다.** 차단 훅 5개가 죽은 줄 몰랐다 | `-File` + stdin 파이프로 교체. **감시자도 감시받아야 한다는 원칙이 실제로 값을 했다** |
| 5 | `pytest.raises(RuntimeError)` 테스트가 **미구현 상태에서 통과** | `NotImplementedError` 는 `RuntimeError` 의 하위 클래스다. 가짜 통과는 진도를 잘못 알린다 | `isinstance` 로 미구현과 정상 거부를 구분 |
| 6 | 테스트 함수명에 `×` 를 써서 `SyntaxError` | 파이썬 식별자에 못 쓰는 문자 | `by` 로 교체 |

⚠ **3·4번이 특히 중요합니다.** 둘 다 **조용히** 깨지는 형태였고,
그대로 뒀으면 「방어선이 있다」고 믿는 채로 방어선이 없는 상태로 몇 세션이 갔을 것입니다.
