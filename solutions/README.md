# solutions/ — 참조 구현

> ⚠⚠ **해당 단계를 통과하기 전에는 열지 마십시오.**

`../CLAUDE.md` §3 검증 루프의 **5번(마지막)** 입니다.

```
1. 구문·실행 오류
2. 단계 테스트
3. 이해 확인 (checkpoint)
4. 기준선 대조
5. ⬅ 참조 구현 대조   ← 여기
```

---

## 왜 마지막인가

**먼저 보면 「내가 어떻게 풀까」가 「정답과 어떻게 다른가」로 바뀝니다.**

그 순간 이 프로젝트의 목적이 사라집니다. 막힌 시간은 낭비가 아닙니다 —
막혔다가 뚫린 지점이 가장 오래 남고, 면접에서 이야기할 수 있는 것도 그 지점입니다
(`../docs/PORTFOLIO.md` §H).

그리고 **참조 구현이 유일한 정답이 아닙니다.** 여러분의 접근이 다르면서도
유효할 수 있습니다. 먼저 보면 그 가능성을 스스로 닫는 것입니다.

---

## 기계적 차단

`guard_spoiler.ps1` 훅이 **`.claude/state/progress.json` 의 `completed_stages` 와 대조**해
아직 통과하지 않은 단계의 파일 열람을 막습니다. Claude 도, Bash 우회도 막힙니다.

단계를 통과하면 `checkpoint` 스킬이 진도를 갱신하고, 그때 열립니다.

---

## 대조할 때 무엇을 볼 것인가

**「같은가」가 아니라 「무엇이 다르고 왜 다른가」를 봅니다.**

| 볼 것 | 왜 |
|---|---|
| **경계 처리** | 0 분모, 빈 입력, k > 후보 수. ⚠ 여기서 가장 자주 갈립니다 |
| **결정 지점** | IDF 스무딩, 토큰화의 하이픈 처리, 동점 정렬. **선택이 달랐다면 그 선택의 이유를 비교하십시오** |
| **수치가 같은가** | 다르면 어느 쪽이 맞는지 **테스트가 아니라 손 계산**으로 확인 |
| **읽히는가** | 포트폴리오는 코드를 읽힙니다 (§13-4) |

⚠ **다르다고 자기 구현을 지우지 마십시오.** 차이와 그 이유를 `../docs/PROGRESS.md` 에 적는 것까지가
이 단계입니다. 그 기록이 README 「배운 것」의 재료입니다.

---

## 현재 상태

⬜ **비어 있습니다.** 참조 구현은 각 단계를 진행하며 함께 만듭니다.

⚠ 사용자가 그 단계를 통과한 **뒤에** 추가합니다. 미리 채워 두면
`guard_spoiler` 가 막더라도 그 파일이 저장소에 있다는 사실 자체가 유혹이 됩니다.
